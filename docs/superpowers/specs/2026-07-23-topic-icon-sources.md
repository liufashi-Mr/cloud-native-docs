# Homepage Topic Icon Sources

The homepage uses the following official SVG artwork, stored locally under
`docs/public/topic-icons/` and referenced at runtime through VitePress `withBase`:

| Asset | Exact source URL |
| --- | --- |
| `containerd.svg` | https://raw.githubusercontent.com/cncf/artwork/main/projects/containerd/icon/color/containerd-icon-color.svg |
| `harbor.svg` | https://raw.githubusercontent.com/cncf/artwork/main/projects/harbor/icon/color/harbor-icon-color.svg |
| `helm.svg` | https://raw.githubusercontent.com/cncf/artwork/main/projects/helm/icon/color/helm-icon-color.svg |
| `argo-cd.svg` | https://raw.githubusercontent.com/cncf/artwork/main/projects/argo/icon/color/argo-icon-color.svg |
| `prometheus.svg` | https://raw.githubusercontent.com/cncf/artwork/main/projects/prometheus/icon/color/prometheus-icon-color.svg |
| `opentelemetry.svg` | https://raw.githubusercontent.com/cncf/artwork/main/projects/opentelemetry/icon/color/opentelemetry-icon-color.svg |
| `grafana.svg` | https://raw.githubusercontent.com/grafana/grafana/main/public/img/grafana_icon.svg |
| `github.svg` | https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-24.svg |

Kubernetes continues to use the existing `docs/public/kubernetes-logo.svg`.
All trademarks and logos remain the property of their respective owners.
Containerd, Helm, and GitHub use a lightening filter only in dark mode to preserve
their contrast without changing the original assets.
